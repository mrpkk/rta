# Установка ṚTA для агента

```bash
claude mcp add --transport http rta https://rta.lat/mcp
```

Или блок в конфиг MCP-клиента:

```json
{
  "mcpServers": {
    "rta": { "url": "https://rta.lat/mcp" }
  }
}
```

Проверка, что всё живо:

```bash
curl -s https://rta.lat/healthz
```

Инструменты:

| Инструмент | Что делает |
|---|---|
| `list_predicates` | Какие пороги вообще доказуемы: имя, значение, размер схемы, понятная формулировка. Бесплатно. |
| `verify_proof` | Проверить доказательство Groth16 того, что скрытое значение достигло порога. Публичные сигналы пусты: верификатор узнаёт, что порог достигнут, и никогда не узнаёт само значение. Нужен одноразовый nonce из `POST /v1/nonce`. |

Оплата: за `verify_proof` платит владелец доказательства (x402, USDC в сети
Base). `list_predicates` — бесплатно.
